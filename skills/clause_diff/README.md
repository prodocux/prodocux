# Multi-document clause diff

> Skill #14 — first-party deterministic clause alignment

## One-liner

Drop in 2+ contract versions and get a clause-by-clause diff in seconds.

## What it does

- Rule-based clause alignment (not an AI summary)
- Local & private — documents stay on your machine
- N-way compare (2, 3, or more)
- CI-ready (`--fail-on-diff`)
- Bilingual (`en` default, `--lang zh-TW`)

## Audience

Legal, procurement, contract managers, editors, QA.

## CLI

See `SKILL.md` and `clause_diff.py --help`.
